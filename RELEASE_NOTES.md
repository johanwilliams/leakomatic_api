# Release Notes - Version 0.2.3

A maintenance release. The complete list of changes is in the [changelog](CHANGELOG.md).

## Leakomatic is in the HACS default catalog

You no longer need to add this repository as a custom repository in HACS: search for **Leakomatic** in HACS and download it. The installation instructions in the README are updated, with a button that opens Leakomatic in HACS directly.

## Added

- **High-resolution icon.** `icon@2x.png` (512×512) is added next to the existing icon and logos in `custom_components/leakomatic/brand/`. The icon looks the same.

## Installation

1. Update through HACS, or copy `custom_components/leakomatic` from this release into your Home Assistant configuration.
2. Restart Home Assistant.
