# Release Notes - Version 0.2.3

A maintenance release. The complete list of changes is in the [changelog](CHANGELOG.md).

## Leakomatic is in the community catalog

You no longer need to add this repository as a custom repository. Search for **Leakomatic** under **Settings → Marketplace** (Home Assistant 2026.11 and newer) or in HACS (older versions). The installation instructions in the README are updated, with a button that opens Leakomatic directly.

If you added Leakomatic as a custom repository earlier, it keeps working and keeps getting updates, also after Home Assistant moves you from HACS to the Marketplace.

## Added

- **High-resolution icon.** `icon@2x.png` (512×512) is added next to the existing icon and logos in `custom_components/leakomatic/brand/`. The icon looks the same.

## Installation

1. Update under **Settings → Updates** (Marketplace or HACS), or copy `custom_components/leakomatic` from this release into your Home Assistant configuration.
2. Restart Home Assistant.
