# Release Notes - Version 0.2.2

A maintenance release. The complete list of changes is in the [changelog](CHANGELOG.md).

## Added

- **Icon and logos in the integration.** Since Home Assistant 2026.3, custom integrations ship their brand images themselves. The Leakomatic icon and logos are now in `custom_components/leakomatic/brand/`. They are the same images as before, and nothing else changes.

## Installation

1. Update through HACS, or copy `custom_components/leakomatic` from this release into your Home Assistant configuration.
2. Restart Home Assistant.
